# ARCANE DUEL — ออนไลน์ 2 คน (Beta)

เกมการ์ดต้นฉบับแบบ 1 ต่อ 1 ในเบราว์เซอร์บนมือถือและคอมพิวเตอร์ ใช้เด็ค **มังกรเมจิกรอยัล** กับ **คิวปิด** อย่างละ 52 ใบ (การ์ด 13 แบบ × แบบละ 4 ใบ) พร้อมเอฟเฟกต์หลัก

## เปิดใช้งานออนไลน์

1. แตก ZIP ให้เป็นโฟลเดอร์ `arcane_online` ที่มี `index.html`, `app.js`, `engine.js` และ `decks.js` อยู่ในโฟลเดอร์เดียวกัน
2. เปิด https://app.netlify.com/drop ด้วยคอมพิวเตอร์ แล้วลาก **โฟลเดอร์** `arcane_online` ลงพื้นที่อัปโหลด (ไม่ใช่ไฟล์ ZIP) จากนั้นรอลิงก์ที่ Netlify ให้
3. เปิดลิงก์เว็บนั้นผ่านมือถือเครื่องที่ 1 เลือกชื่อและเด็ค กด **สร้างห้อง**
4. กด **คัดลอกลิงก์ชวนเพื่อน** ส่งลิงก์ให้มือถือเครื่องที่ 2
5. มือถือเครื่องที่ 2 เปิดลิงก์ เลือกชื่อและเด็ค กด **เข้าห้องและเริ่มดวล**
6. เจ้าของห้องเล่นก่อน ผลการเล่นจะอัปเดตถึงกันทันที

## ขอบเขตของเวอร์ชันทดลอง

- เกมทำงานในเบราว์เซอร์ ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์เกมที่เราควบคุมเอง
- เชื่อมต่อแบบ peer-to-peer (WebRTC) ด้วย PeerJS โดยพึ่งเซิร์ฟเวอร์สัญญาณสาธารณะของ PeerJS จึง *ไม่ได้รับประกัน* การเชื่อมต่อบนทุก Wi-Fi/4G/5G (บาง NAT/firewall ต้องใช้ TURN server)
- เจ้าของห้องเป็นผู้ประมวลผลกติกาและเป็น authority หลัก คนเข้าห้องจะเห็นเฉพาะไพ่บนมือตัวเองและจำนวนไพ่ฝ่ายตรงข้าม (แต่เจ้าของห้องควบคุมเกมในเครื่องตัวเอง ระบบนี้ไม่เหมาะกับการแข่งขันที่ต้องกันโกง)
- เมื่อคนใดคนหนึ่งปิดหน้าเว็บหรือหลุดจากห้อง เกมจะหยุด ต้องสร้างห้องใหม่; ไม่บันทึกเกมระหว่างเล่น
- ศิลปะการ์ดใช้สัญลักษณ์/อีโมจิ *แทนภาพอนิเมะ* รอเติมภาพจริงได้ในรุ่นถัดไป
- เอฟเฟกต์เลือกเป้าหมายของการ์ดที่ลงสนามอัตโนมัติ: เลือกตัวที่เข้าเงื่อนไขตัวแรก; เวทมนตร์และการโจมตีเลือกเป้าหมายเองได้
- สังเวยอัตโนมัติตาม ATK ต่ำสุด, ทิ้งการ์ดอัตโนมัติจากท้ายมือ, กับดักเปิดอัตโนมัติตามเงื่อนไข, มอนสเตอร์ในท่าป้องกันไม่สามารถโจมตีได้, การ์ดที่โจมตีถูกจำกัดเทิร์นละหนึ่งครั้ง
- รุ่นนี้เป็น PvP Beta เพื่อให้ทดลองดวลกัน **ไม่ใช่เกมการแข่งขันที่สมบูรณ์**

## นักพัฒนา

ไม่ต้องติดตั้ง npm/Node.js สำหรับเว็บ เนื่องจากใช้ JS ธรรมดา ไฟล์ `decks.js` เก็บข้อมูลการ์ด ส่วน `engine.js` คำนวณกฎ และ `app.js` ดูแล UI/การเชื่อมต่อ

เปิดผ่าน `http://localhost` เพื่อทดสอบในเครื่อง หรือ deploy Netlify เพื่อเล่นจริงบนอินเทอร์เน็ต ใช้ PeerJS 1.5.5 จาก jsDelivr และ PeerJS Cloud สำหรับ signalling
