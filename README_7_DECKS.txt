ARCANE DUEL 7 DECKS — PvP Beta

7 decks, 52 cards each (13 unique card names x4), 364 physical cards.
Original decks: Dragon Magic Royal, Cupid.
Added decks: Dream Bunny Paradise, Floral Empress, Five Relics, Vampire Dynasty, Astral Guardians.

How to publish: upload the CONTENTS of arcane_online folder (index.html at site root) to existing Netlify site's Deploys. Use manual deploy; do not upload ZIP as a single HTML file.

Images: original 26 card illustrations from previous build; the 65 new images are cropped concept art from a single themed poster, visually differentiated but not individually generated paintings. Further art production recommended.

Five Relics: hold all 5 distinct relic piece IDs RL01-RL05 in your hand to win immediately. Four copies of each. No need to summon them. Card draws are checked by host engine. This is an original mechanic inspired by assembly victories.

Note: PeerJS requires internet, public signaling service and compatible network NAT; this beta is not guaranteed to connect across every network. The host is authoritative for state, but not hardened against malicious clients. This is not production-grade matchmaking.

New decks use simplified, implemented effects; the exact on-card Thai descriptions are in decks.js. Some legacy deck effects remain beta simplified.
